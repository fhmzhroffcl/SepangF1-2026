# Sepang Race Hub

A mobile-first race-weekend companion for the Formula 1 Gulf Air Bahrain Grand Prix in Malaysia at Sepang International Circuit, 2–4 October 2026.

## Live app

https://sepang-race-hub.fhmzhr.chatgpt.site

## Run locally

```bash
npm install
npm run dev
```

## Included flows

- Friday–Sunday session switching
- Sepang weather and tyre-strategy planning scenario
- Interactive circuit-zone guide
- Personalised arrival recommendation
- Persistent race-weekend packing checklist

Event facts are based on the official Sepang International Circuit announcement. Weather values are illustrative planning scenarios, clearly labelled in the interface.
